# FEM2D · 二维有限元分析教学工具（静力 + 自由振动）

一个在浏览器中运行的平面应力 / 平面应变线弹性有限元分析工具。学习者可以：

- 逐点点击勾勒封闭多边形，或选用参数化模板（矩形梁、L 形、带圆孔板），生成后顶点可拖动；
- 对封闭区域做约束 Delaunay 三角剖分，调节全局种子间距，查看节点/单元数、内角逐项、单元质量统计；
- 设置材料（E、ν、厚度、质量密度 ρ，平面应力 / 平面应变切换）、约束（固定、水平 / 竖直单向滑移）、节点集中力、分布面力与全域体力；
- **静力分析**：单元刚度 → 整体装配 → 边界条件 → 求解 Ku=F → 应力回代，画布叠加变形图与 σx/σy/τxy/von Mises 应力云图；
- **自由振动分析**（与静力平级的独立能力）：装配质量矩阵 → 自由度缩减消去约束 → 求解广义特征值问题 (K−ω²M)φ=0 →
  给出按频率升序的前若干阶弹性模态（Hz 与 rad/s 并列）、质量归一化振型，可逐阶叠加显示并来回摆动动画；
- 对同一几何逐级加密网格，记录静力「单元数 — 最大应力 / 位移」收敛曲线，观察网格无关性。

## 自由振动分析（本次新增）

求解无外载、只有惯性与弹性相互作用时的固有特性。两种分析共用同一网格、材料与约束，但走各自独立的求解链路：

- **质量矩阵**：材料面板新增密度 ρ（缺省取钢 7.85×10⁻⁶ kg/mm³，mm-N-MPa 单位制）。每个 CST 单元按 ρ、厚度与面积形成
  **一致质量矩阵**（非对角，保留单元内耦合，∫NᵀN）或**集中质量矩阵**（纯对角，质量凝聚到节点），二者都沿与刚度矩阵
  **完全相同的自由度编号与 CSR 组织方式**装配，保证 K、M 严格对齐。两种离散系统性不同（一致质量偏柔、集中质量偏刚，
  高频段差异尤其明显），可在界面一键切换对照。
- **与约束协同**：被固定/滑移锁住的自由度不参与振动，在消去这些自由度后的**缩减系统**上求解；约束不足、仍有刚体运动时，
  自动识别整体平移/转动零能模态（x、y 平移 + 转动）并从结果中剔除，只返回带弹性变形的模态。
- **低频特征值策略**：采用**移位-求逆子空间迭代**（shift-invert subspace iteration），把「最小特征值」翻转为求逆算子
  最大的方向，稳定锁定低频端；迭代中始终对试探向量做**关于质量矩阵的 M-正交归一**，使对称结构的重频/近频模态作为一个
  子空间整体收敛，不漏不并。小系统稠密 LDLᵀ，大系统 IC(0) 不完全 Cholesky 预处理共轭梯度（两阶段自适应移位）。
- **可核验性**：振型质量归一（φᵀMφ=1、跨阶 φ_iᵀMφ_j=0），频率满足 Rayleigh 商 ω²=φᵀKφ/φᵀMφ，相对残差随每阶给出，
  这些性质均由自动化测试锁定。
- **解析对照算例**：悬臂梁低阶弯曲频率对照 Euler-Bernoulli 闭式解
  f_n=β_n²/(2π)·√(EI/(ρAL⁴))（β_nL=1.8751, 4.6941, 7.8548）；一端固定杆纵向频率对照
  f_n=(2n−1)/(4L)·√(E/ρ)。细网格下数值解收敛到解析值邻域。

> 本功能聚焦二维结构自由振动模态，不含时程响应、阻尼、受迫振动或频响函数。

## 内核理论要点

- 单元：三节点常应变三角形（CST）。形函数梯度与面积由节点坐标直接得到，
  `B(3×6)`，`Ke = t·A·Bᵀ·D·B`。
- 平面应力 `D = E/(1−ν²)[1, ν, 0; ν, 1, 0; 0, 0, (1−ν)/2]`；
  平面应变 `D = E/((1+ν)(1−2ν))[1−ν, ν, 0; ν, 1−ν, 0; 0, 0, (1−2ν)/2]`。
- 整体刚度与质量均为对称 CSR，沿同一自由度排布装配；静力约束按自由度置 1 消行消列（保持对称），
  自由振动则直接在自由自由度缩减系统上求解。
- 静力求解：≤500 自由度用稠密 LDLᵀ 并以小主元计数报告无约束机构数量；
  更大系统用 Jacobi 预处理共轭梯度，出现非正曲率 / 不收敛时给出约束不足提示，不崩溃。
- 应力：CST 单元内 σ 为常数；节点应力取相邻单元平均用于连续色带。
- 自由振动：广义特征值 `Kφ = ω²Mφ`。一致质量 `Me = ρtA/12·(2 对角, 1 非对角)`，
  集中质量每节点两方向各 `ρtA/3`。移位-求逆子空间迭代锁定低频端、M-正交归一保证重频完整；
  几何刚体候选（两平移一转动）识别零能模态并剔除。

## 内置标准算例

1. **悬臂梁**（端部集中力 / 自由振动）：静力端部挠度 δ=PL³/(3EI)、固定端 σ=Mc/I；
   低阶弯曲频率趋于 Euler-Bernoulli `f=β²/(2π)√(EI/ρAL⁴)`，纵向频率趋于 `(2n−1)/(4L)√(E/ρ)`。
2. **悬臂杆纵向自由振动**：细长杆前几阶纵向频率对照一维轴向波动闭式解。
3. **带圆孔板单向拉伸（四分之一对称模型）**：Kirsch 孔边应力集中系数 K=3。

## 自动化测试（覆盖内核正确性，可独立运行）

```bash
npm test -w @fem2d/core
# 或：cd packages/core && npm test
```

测试锁住以下结论（共 57 项）：

- 单个三角单元 Ke **对称**；恰好有 **3 个零能模式**（x、y 刚体平移 + 转动），其余特征值为正；
- 规则网格**严格分片试验**（σx 精确等于施加值、位移场严格线性），非规则 Delaunay 网格近似成立；
- 悬臂梁细网格最大位移与梁理论偏差 < 12%，且随加密收敛；固定端弯曲应力与 σ=Mc/I 一致；
- **无约束 / 约束不足 → 静力抛 SingularMatrixError**（不崩溃，给出机构自由度提示）；
- 载荷放大 k 倍，位移与应力**严格等比例**放大；
- **平面应力与平面应变结果不同**，纯弯曲位移比 ≈ 1−ν²；
- 支反力与外载满足合力、合力矩平衡；体力合力等于 γ·V·t；
- 网格剖分合法（无重叠、无悬挂节点、边界完整覆盖），孔内无单元；
- 网格无关性研究单调加密、孔板应力集中系数趋于 3；
- **单元一致/集中质量**对称、总质量 = ρ·V·t；整体 K、M 自由度排布严格对齐；集中质量非对角全 0；
- **模态质量归一** φᵀMφ=1、**跨阶质量正交** φ_iᵀMφ_j=0；Rayleigh 商 ω²=φᵀKφ/φᵀMφ 自洽；
- 频率为正、升序、约束自由度振型为零；**自由/欠约束结构识别并剔除 3/2 个刚体模态**后仍稳定给出最低弹性频率；
- **一致质量与集中质量解出系统性不同的频率**（差异随模态阶次增大，均在解析值近旁）；
- **悬臂梁前两阶弯曲频率随加密收敛到 Euler-Bernoulli 闭式解（细网格偏差 < 8%）**；
- **悬臂杆前两阶纵向频率收敛到 (2n−1)/(4L)√(E/ρ)（偏差 < 4%）**；请求 10 阶时近频模态不漏不重、彼此正交。

## 单位制

界面不绑定单位，建议统一使用 **mm – N – MPa**（钢材 E=210000 MPa）。所有力、应力、位移量纲在该单位制下自洽。
自由振动的频率量纲：1 N = 1 kg·mm/s²，故质量密度取 **kg/mm³**（钢 ρ=7.85×10⁻⁶ kg/mm³），
由此得到的圆频率 ω 单位为 rad/s、频率 f=ω/(2π) 单位为 Hz。
